# Contributing to Network World Model API

## Development Rules

1. **Contract-First**: Always treat `contracts/openapi/network-world-state.openapi.json` as the single source of truth.
2. **Never Hand-Edit Generated Code**:
   - `go/worldstate/types.gen.go` is generated by `oapi-codegen`.
   - `python/network_world_model_api/models.py` is generated by `datamodel-code-generator`.
   - Any manual changes will fail CI `make verify` and will be overwritten.
3. **Local Testing**:
   - Run `make test` locally before submitting a pull request.
   - Run `make verify` to ensure zero drift between contract and generated code.
